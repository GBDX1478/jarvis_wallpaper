# J.A.R.V.I.S. — fond d'écran interactif pour Android

Fond d'écran animé façon Jarvis : réacteur animé, heure, date, batterie (anneau), mémoire,
stockage, température, et **rapport vocal** quand on touche le réacteur.
Fond personnalisable avec vos propres images (diaporama possible), 6 couleurs d'interface.

## Installer
1. Ouvrez l'onglet **Releases** de ce dépôt depuis le téléphone et téléchargez `Jarvis.apk`.
2. Ouvrez le fichier : Android demande d'autoriser l'installation depuis le navigateur → autorisez.
3. Lancez l'appli **Jarvis** → « Activer le fond d'écran ».

Chaque envoi sur la branche principale reconstruit l'APK automatiquement (GitHub Actions).
